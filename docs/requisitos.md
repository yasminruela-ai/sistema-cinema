Requisitos Funcionais
RF01

O sistema deve permitir o cadastro de cinemas.

RF02

O sistema deve permitir o cadastro de filmes.

RF03

O sistema deve permitir o cadastro de sessões.

RF04

O sistema deve registrar a quantidade de público em cada sessão.

RF05

O sistema deve permitir a consulta de filmes em cartaz.

RF06

O sistema deve permitir a consulta de sessões disponíveis por cinema.

RF07

O sistema deve exibir informações dos filmes, como gênero, diretor e elenco.

RF08

O sistema deve calcular o total de público por sessão.

RF09

O sistema deve calcular o total de público por filme.

RF10

O sistema deve calcular o total de público por cinema.

Regras de Negócio
RN01

Cada sessão deve estar vinculada a apenas um filme.

RN02

Um cinema pode possuir várias sessões.

RN03

A quantidade de espectadores não pode ultrapassar a capacidade do cinema.

RN04

Toda sessão deve possuir horário definido.

RN05

Um filme pode ser exibido em diferentes cinemas.

RN06

O sistema deve armazenar informações de diretor, elenco e gênero dos filmes.
